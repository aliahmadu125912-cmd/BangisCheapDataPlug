# Bangis Cheap Data Plug Android App

This project wraps the website:
https://bangischeapdataplug.quark.ng

## Build
Open this folder in Android Studio, allow Gradle sync, then:
- Build > Generate App Bundles or APKs > Generate App Bundle
- Select release
- Create/use a signing key when prompted.

For Google Play, upload the signed `.aab` file in Play Console.

## Important
Before publishing, add a public Privacy Policy URL and complete Google's Data safety/App content forms.
